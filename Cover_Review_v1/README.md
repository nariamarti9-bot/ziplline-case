## Review status

**This is a design proof, not the final printing file.** Artwork/design approval is pending. Generated background art is 1465 × 1073 px, approximately 113 ppi at this full-cover size. The title, author, blurb and spine use sharp, live, embedded-font PDF text. Final print preparation must address artwork resolution; simply changing DPI metadata would not add detail. A 300-dpi full-size raster export requires at least 3896 × 2850 pixels, and any resizing must be described honestly as upscaling.

The editable layout is in `build_cover.py` and `editable-type-layout.json`. Exact dimensions, image hashes and production notes are in `cover-specifications.json`.

The project instruction in [AGENTS.md](/workspace/book-assets/Zipline_Interior_Codex/AGENTS.md:16) says: “Record user-approved assets before placing them.” This layout is offered for approval before a final production cover is delivered.
